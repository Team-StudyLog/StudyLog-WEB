# StudyLog-WEB

스터디로그는 **공부를 기록하고 AI가 퀴즈를 생성하여 복습하는 학습 기록 웹앱 서비스**입니다.
<a href="https://studylog-nine.vercel.app/UX320" target="_blank" rel="noopener noreferrer">
  웹사이트 바로가기
</a>
<br />
<br />

## ⭐ 서비스 주요 기능

| 기능             | 설명 |
|------------------|------|
| 📚 **학습 기록** | 학습 내용을 기록, 수정, 삭제할 수 있어 학습 이력을 손쉽게 관리할 수 있어요. |
| 🧠 **퀴즈 생성** | 난이도와 개수를 설정하여 맞춤형 퀴즈를 자동으로 생성합니다. |
| 🗂️ **카테고리 관리** | 자신만의 카테고리를 만들어 학습 내용을 체계적으로 정리할 수 있습니다. |
| 🤝 **팔로우 & 공유** | 다른 사용자를 팔로우하고 학습 기록을 공유할 수 있어요. 함께 배우며 동기부여를 얻을 수 있습니다. |
| 🏅 **뱃지 & 스트릭 시스템** | 연속 학습을 달성하면 뱃지를 획득하고, 스트릭 페이지에서 꾸준한 학습 내역을 시각적으로 확인할 수 있습니다. |

<br />
